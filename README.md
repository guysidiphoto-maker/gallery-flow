# Pixflow

Online galleries for photographers: public gallery viewer, photographer dashboard,
client portal and marketing site.

| Folder | What's in it |
|---|---|
| [`gallery-web/`](gallery-web/README.md) | The web app (Vite + React SPA) and its Vercel functions (`api/`). Start here. |
| `supabase/` | Database migrations (`migrations/`) and edge functions (`functions/`). |
| `scripts/` | Ops helpers that run against the live project (gallery monitor, originals reconcile, email preview). |
| `brand/` | Logo and icon source files. |
| `docs/` | Architecture notes, audits and plans. |
